# Crypto Investment Manager

A Python-based crypto investment management system that analyzes historical price data, calculates risk metrics in parallel, stores insights in SQLite, and generates rule-based investment recommendations.

## Features
- CSV-based crypto price ingestion
- Time-series return and volatility (risk) calculation
- Parallel risk computation using ThreadPoolExecutor
- SQLite database for persistent storage
- Rule-based investment allocation
- Risk alerts based on thresholds
- Stress testing under simulated market crashes
- CSV report generation

## Technologies Used
- Python
- Pandas
- SQLite
- Concurrent Futures (Parallel Execution)
